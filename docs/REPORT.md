## Фасетный фильтр на 10000 историях

Отдельная БД, 60 прогонов на сценарий; время = счётчики всех фасетов + одна страница результатов (два запроса параллельно).

| Сценарий | Найдено | p50 | p95 | max |
|---|---|---|---|---|
| no filter | 10000 | 37.9 мс | 40.1 мс | 58.7 мс |
| 1 facet (season) | 3428 | 22.8 мс | 23.9 мс | 27.1 мс |
| 3 facets | 539 | 16.6 мс | 21 мс | 23.6 мс |
| 5 facets + category | 9 | 20.3 мс | 22.3 мс | 22.4 мс |
| bbox (Europe) | 27 | 3.9 мс | 4.7 мс | 5.4 мс |
| sort popular | 2455 | 18.8 мс | 21.2 мс | 22.3 мс |

Требование «< 100 мс» выполнено с запасом. Как достигнуто: B-tree индексы по категории, стране, региону, бюджету, типу, длительности; GIN по массивам сезонов и тегов; полностью отфильтрованная выборка материализуется один раз (`WITH base AS MATERIALIZED`), неактивные фасеты группируются из неё, отдельный скан нужен только активным фасетам.
