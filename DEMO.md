# Демо «Подорожники+» за одну команду

## Для Claude Code / AI-агента

Склонируй репозиторий, выполни `scripts/demo.sh` (на Windows `scripts/demo.ps1`), ничего не генерируй и не меняй код, после запуска открой ссылки из вывода скрипта и проверь, что главная, `/stories` с фильтром, `/map`, `/guides` и `/admin` открываются.

```bash
git clone https://github.com/realmag777/travel-stories.git && cd travel-stories && bash scripts/demo.sh
```

Windows (PowerShell):

```powershell
git clone https://github.com/realmag777/travel-stories.git; cd travel-stories; powershell -ExecutionPolicy Bypass -File scripts\demo.ps1
```

## Что нужно

- Docker Desktop (Windows, macOS) или Docker Engine с плагином compose v2 (Linux). Node.js не нужен.
- Свободный порт **8080** на localhost (другой задаётся одной строкой, см. «Частые проблемы»).
- Около 1,5 ГБ на диске под образ и данные.

## Запуск

1. Склонируйте репозиторий и перейдите в папку.
2. Выполните `bash scripts/demo.sh` (Linux/macOS) или `powershell -ExecutionPolicy Bypass -File scripts\demo.ps1` (Windows). Если есть Node.js, можно `npm run demo`.
3. Дождитесь вывода со ссылками. Первый запуск: 2–5 минут на новой машине (скачиваются базовые образы, собирается образ приложения примерно за 35 с, Postgres восстанавливает снимок, картинки копируются в том). На машине с Docker-кэшем от клонирования до работающего сайта проходит около 80 с. Повторные запуски занимают секунды.

Скрипт проверяет Docker, создаёт `.env` из `.env.demo` (если `.env` нет), поднимает `docker-compose.demo.yml`, ждёт healthcheck и печатает ссылки.

Данные берутся только из репозитория: база — `demo/db/demo.dump`, картинки — `demo/uploads`. При старте ничего не импортируется с оригинала и ничего не генерируется. Повторный запуск данные не перетирает.

## Ссылки и вход

| Что | Адрес |
|---|---|
| Сайт | http://localhost:8080 |
| Админка | http://localhost:8080/admin — логин `admin`, пароль `demo-admin-2026` |
| API (Swagger) | http://localhost:8080/docs |
| Карта | http://localhost:8080/map |
| Гиды | http://localhost:8080/guides |

Логин и пароль заданы в `.env.demo` (`ADMIN_USER`, `DEMO_ADMIN_PASS`). Это только для локального демо.

## Что показать за 5 минут

1. **Главная** — та же вёрстка, что у оригинала «Подорожники». Ниже секция «Популярні гіди».
2. **Фильтр** — «Історії» → в панели слева выберите сезон «Весна», бюджет «Низький». Результаты и счётчики меняются без перезагрузки, адрес — ЧПУ вида `/stories/filter/season-spring/budget-low`, им можно поделиться.
3. **Поиск обычным языком** — в строке над фильтром введите «куди поїхати в травні з дітьми недорого». Запрос разложится на чипы Весна · Низький · Сім'я, лишнее снимается крестиком. LLM не нужен, работает разборщик на правилах.
4. **Карта** — переключатель «Карта» в каталоге или `/map`: кластеры, превью в попапе, галочка «Шукати у видимій області» пересчитывает фильтр.
5. **Бронирование гида** — «Гіди» → карточка → «Забронювати» → услуга, день, время, имя и e-mail → страница подтверждения с деталями и одноразовой ссылкой отмены. Письмо в демо пишется в лог: `docker compose -f docker-compose.demo.yml logs app`.
6. **Админка** — `/admin`: дашборд, только что созданная бронь в «Бронювання» (подтвердить или отменить), редактор истории с картой и переводами, словари, очистка демо-контента.
7. **Языки** — внизу страницы English / Español.

## Сброс к снимку

Всё, что изменили в демо (брони, правки в админке, загруженные картинки), удаляется, и демо поднимается заново из снимка:

```bash
bash scripts/demo-reset.sh
```

Windows: `powershell -ExecutionPolicy Bypass -File scripts\demo-reset.ps1`, с Node.js — `npm run demo:reset`.

Остановить, не теряя данных: `docker compose -f docker-compose.demo.yml down`.

## Интернет

Тайлы карты грузятся с OpenStreetMap, поэтому для карты нужен интернет. Всё остальное работает офлайн: шрифты, Leaflet, стили и картинки лежат в репозитории, CDN не используются. Интернет нужен ещё один раз — при первой сборке образа, чтобы скачать образы Docker и npm-пакеты.

## Частые проблемы

- **Порт 8080 занят.** Скрипт сообщит об этом. Откройте `.env` (если его ещё нет — `.env.demo`), поменяйте `APP_PORT=8080` на свободный, например `APP_PORT=8090`, и запустите скрипт снова. Ссылки в выводе поменяются сами.
- **Docker не запущен.** Скрипт пишет «Docker не запущен». Запустите Docker Desktop, дождитесь зелёного статуса и повторите.
- **Нет снимка (`demo/db/demo.dump` или `demo/uploads`).** Скорее всего, клон неполный. Сделайте `git clone` заново, без `--depth`/`--filter`. Архивов для скачивания нет: картинки лежат прямо в репозитории.
- **Ошибка сети Docker «all predefined address pools have been fully subnetted».** Демо использует свою подсеть `10.77.32.0/24`. Если она пересекается с вашей сетью, задайте в `.env` другую, например `DEMO_SUBNET=10.99.12.0/24`.
- **Долго «жду готовности».** Посмотрите `docker compose -f docker-compose.demo.yml logs app db`. Сброс к чистому снимку — `scripts/demo-reset`.
